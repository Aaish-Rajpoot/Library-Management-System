# 📚 Library Management System 

A simple console-based library system implemented in C++ using Object-Oriented Programming and Data Structures like Linked Lists and Queues.

## 🚀 Features
- Add, view, delete books
- Register library members
- Borrow and return books
- Queue system for book reservations
- Data persistence via file I/O

## 🧰 Technologies
- C++
- OOP: Classes & Inheritance
- DSA: Linked Lists, Queues
- File Handling

## 📂 Project Structure
- `main.cpp` — Program logic
- `Book.h`, `Member.h`, `Library.h` — Classes and header files
- `data.txt` — Data storage (optional)
